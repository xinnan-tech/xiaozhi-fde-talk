# 小智方糖 使用教程

本教程只面向**管理员**视角：从注册账号开始，到完成一次访谈、导出报告。如果你只是想试用，按顺序读完第 1～6 节即可上手。

部署 / 启动后端与 ASR 服务请看根目录 `README.md`「快速开始」一节，本文不再重复。

---

## 1. 注册首位管理员

打开浏览器，访问 `http://localhost:8848`。

如果系统里还没有任何账号，登录框会出现 **「去注册」** 链接；点它。

填三样东西：

- **用户名**：4 到 32 位的字母、数字、下划线、连字符，不能和别人重名
- **密码**：长度与字符种类有最低要求（系统拒绝太短、太简单的密码，按提示来即可）
- **确认密码**：再输一次

点「注册」。

**系统里第一个注册成功的账号会自动成为超级管理员**，后续注册的普通账号只有普通权限。

注册成功后页面会让你登录；输入刚才的用户名密码登录。

> 如果你看不到「去注册」链接，说明系统里已经有用户了，并且管理员把注册关掉了。请联系当前管理员给你开账号。

---

## 2. 进入系统配置

登录后默认进「访谈主页」（左侧菜单第一个）。普通管理员这一步什么都不用做，直接跳到第 3 节。

**超级管理员** 还要先做一些配置：

点左下角菜单里的 **「系统配置」**（图标是齿轮）。页面顶部会出现一组配置分组。

```
LLM  |  ASR  |  OCR
```

---

## 3. 填 LLM 密钥

点 **LLM** 分组，至少填这三项：

- `api_key`：大模型厂商给你的密钥
- `base_url`：API 接入地址（OpenAI 兼容协议）
- `model`：模型名，例如 `qwen-plus`、`gpt-4o-mini`

填完点页面上的保存。

> 这一步不填的话，等下创建访谈会被 LLM 拒绝，转写出来的内容也走不了辅导。

---

## 4. 运行自检

LLM 填好后，回到配置页右上角，点 **「运行自检」** 按钮。

弹窗里会列出三类检查：

- **全部**：一次跑 ASR、LLM、OCR 三个组件
- **ASR**：单跑语音识别
- **LLM**：单跑大模型
- **OCR**：单跑图片识别

第一次点选 **「全部」**。每张卡片都会显示 `ok` 或具体失败原因。

常见失败原因：

- LLM 红字 → 多半是密钥错、或 `base_url` 填成「聊天界面」而不是 API 地址
- ASR 红字 → 看一下 FunASR Docker 容器是不是没起来：`docker compose ps` 应能看到 `funasr` 在运行
- OCR 红字 → 如果你暂时不用 OCR 提取图片内容，可以跳过；想用就在 OCR 分组里配上 key 后重跑自检

全部绿灯后关掉弹窗，进入下一步。

---

## 5. 创建访谈

回到 **「访谈主页」**，点页面上的 **「新建访谈」**。

弹窗里会让你选模板、填访谈对象、背景与目标。模板里预置了「必问问题」清单，不满意可以换：

- 「**客户类型**」：被访谈的人大概是什么角色
- 「**客户背景**」：他所在的公司 / 行业 / 现状
- 「**访谈目标**」：你这次最想搞清的问题

填完点「创建访谈」，会自动跳进访谈页。

---

## 6. 跑访谈

访谈页里从上到下分三块：

- **上方**：实时的转写文本（你说的话 / 对方的话会一边识别一边上屏）
- **右侧**：辅导清单（系统根据对话给你「下一个该问什么」「哪些关键点还没问到」的提示）
- **下方**：控制按钮

### 开始 → 暂停 → 继续 → 结束

- 点 **「开始访谈」**，浏览器会请求麦克风权限，授权后转写开始
- 中途需要去接电话、回消息 → 点 **「暂停访谈」**：状态变成「已暂停」，列表里的卡片立即变灰，可以随时回来点「继续」
- 这场访谈聊完了 → 点 **「结束访谈」**：状态变成「已结束」，不能再继续

「暂停」和「结束」的区别：

- **暂停**：状态写盘成 `suspended`。如果 WS 连接本身没断，你可以继续转写；如果你离开页面、关闭浏览器，只要服务端还在「存活窗口」内（默认 60 秒）回来重连，点「继续」就能从暂停的位置继续
- **结束**：状态写盘成 `ended`，WS 连接关闭、辅导引擎收尾、报告开始生成——结束后就真的结束了

### 辅导清单的操作

右侧每条提示有两种动作：

- **跳过本次**：本次访谈不聊这个，但下次访谈还会再出现
- **忽略**：以后这类提示永远不再出现；已忽略的项可点「取消忽略」恢复

「跳过」不可逆（普通界面没有「恢复」按钮）。

---

## 7. 查看并导出报告

访谈「已结束」后：

1. 回到访谈主页，状态为「已结束」的卡片会多一个 **「查看报告」** 按钮
2. 点进去，报告会展示结构化需求文档
3. 页面上有「导出」按钮，格式可选 **Markdown / HTML / Word** 之一

报告生成是异步的——结束访谈后立刻点「查看报告」会提示「报告未就绪」，等几秒再点一次就行。

---

## 8. 管理用户

「系统配置」旁边是 **「用户管理」** 菜单（仅管理员可见）。

可以做两件事：

- 看当前系统里所有账号
- **重置某个用户的登录密码**（找不到原密码、又不想删账号时用）

> 「用户管理」菜单只在你注册功能开启时出现。关掉注册后菜单会隐藏。

---

## 9. 常见问题

**看不到「去注册」链接？**
→ 系统已经有用户、且注册已关闭。请联系管理员开账号。

**自检 LLM 失败？**
→ 先看密钥是否对，再看 `base_url` 是否正确（很多厂商控制台上的「对话」地址 ≠ API 地址）。

**自检 ASR 失败？**
→ 确认 FunASR Docker 容器在跑：`docker compose ps`。

**访谈跑到一半想暂停又不想结束？**
→ 点「暂停访谈」即可，不要直接关浏览器。直接关浏览器且不在存活窗口（默认 60 秒）内回来，连接会被服务端收尾。

**暂停后想「彻底结束」这段访谈？**
→ 进访谈页点「结束访谈」就行，会写盘 ended 并生成报告。

**报告一直在「未就绪」？**
→ 报告生成依赖 LLM。打开「自检 → LLM」看是否能复现失败；如果 LLM 自检通过但报告一直不出，看后端日志找具体原因。

**密码忘了？**
→ 让管理员在「用户管理」里点「重置密码」。

## 10. 看完之后

到这里你已经掌握了管理员的完整日常动作：

注册 → 配置 LLM → 自检 → 建访谈 → 跑访谈 → 暂停 / 继续 / 结束 → 导出报告

如果还要做集成（自己写脚本跑、嵌入到别的产品里），请看：

- `docs/http-api.md`：HTTP 接口契约
- `docs/websocket-protocol.md`：访谈页 WS 通信协议
