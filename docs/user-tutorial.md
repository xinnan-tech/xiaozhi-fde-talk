# 小智方糖 使用教程

本教程只面向**管理员**视角：从注册账号开始，到完成一次访谈、导出报告。如果你只是想试用，按顺序读完第 1～6 节即可上手。

部署 / 启动主应用请看根目录 `README.md`「快速开始」一节，本文不再重复。

---

## 1. 注册首位管理员

打开浏览器，访问 `http://localhost:8848`。

如果系统里还没有任何账号，登录框会出现 **「去注册」** 链接；点它。

填三样东西：

- **用户名**：4 到 32 位的字母、数字、下划线、连字符，不能和别人重名
- **密码**：长度与字符种类有最低要求（系统拒绝太短、太简单的密码，按提示来即可）
- **确认密码**：再输一次

点「注册」。

**系统里第一个注册成功的账号会自动成为超级管理员**，后续注册的普通账号只有普通权限。

注册成功后页面会让你登录；输入刚才的用户名密码登录。

> 如果你看不到「去注册」链接，说明系统里已经有用户了，并且管理员把注册关掉了。请联系当前管理员给你开账号。

---

## 2. 进入系统配置

登录后默认进「访谈主页」（左侧菜单第一个）。普通用户这一步什么都不用做，直接跳到第 4 节。

**超级管理员** 还要先做一些配置：

点左侧菜单里的 **「系统配置」**。

配置项分三组，按需填：

- **AI 大模型**（必填）：见 [AI 大模型配置](llm-config.md) — 阿里云百炼 / DeepSeek / OpenAI 等
- **语音识别**（不填也能用，但说话时没转写）：见 [语音识别配置](asr-config.md) — 豆包流式 API / 本地 FunASR
- **图片识别**（可选，纯语音访谈不用填）：见 [图片识别配置](ocr-config.md) — 百度 / OpenAI 兼容

---

## 3. 运行自检

LLM / ASR / OCR 都填好后，回到配置页右上角，点 **「运行自检」** 按钮。

弹窗里会列出三类检查：

- **全部**：一次跑 ASR、LLM、OCR 三个组件
- **ASR**：单跑语音识别
- **LLM**：单跑大模型
- **OCR**：单跑图片识别

第一次点选 **「全部」**。每张卡片都会显示 `ok` 或具体失败原因。

常见失败原因：

- AI 大模型红字 → 多半是密钥错、或 `base_url` 填成「聊天界面」而不是 API 地址（见 [AI 大模型配置](llm-config.md)）
- 语音识别红字 → 看一下 FunASR Docker 容器是不是没起来；或豆包的 `appid` / `access_token` 填错（见 [语音识别配置](asr-config.md)）
- 图片识别红字 → AK / SK 漏填、或者百度账号还没开通文字识别服务。如果你不做图片提取，可以跳过图片识别自检

全部绿灯后关掉弹窗，进入下一步。

> **基础能力保证**：语音识别和 AI 大模型正常就够了，图片识别纯语音访谈用不到。

---

## 4. 创建访谈

回到 **「访谈主页」**，点页面上的 **「新建访谈」**。

弹窗里会让你选模板、填访谈对象、背景与目标：

- 被访谈的人大概是什么角色
- 他所在的公司 / 行业 / 现状
- 你这次最想搞清的问题是啥，比如你想了解他对某个系统的建设需求，简单写写，对智能辅助很有必要

填完点「创建访谈」，会自动跳进访谈页。

---

## 5. 跑访谈

访谈页里从上到下分三块：

- **左侧**：辅导清单（系统根据对话给你「下一个该问什么」「哪些关键点还没问到」的提示）
- **右方**：实时的转写文本（你说的话 / 对方的话会一边识别一边上屏）
- **右上方**：控制按钮

### 开始 → 暂停 → 继续 → 结束

- 点 **「开始访谈」**，浏览器会请求麦克风权限，授权后转写开始
- 中途需要去接电话、回消息 → 点 **「暂停访谈」**：状态变成「已暂停」，列表里的卡片立即变灰，可以随时回来点「继续」
- 这场访谈聊完了 → 点 **「结束访谈」**：状态变成「已结束」，不能再继续

### 辅导清单的操作

左侧每条提示有两种动作：

- **忽略**：本次访谈不聊这个，就不出现在待问清单里了

边聊的过程中，AI会自动把已经澄清的内容标注好。用户只要在访谈过程中瞄一眼待问清单。

---

## 6. 查看并导出报告

访谈「已结束」后：

1. 回到访谈主页，状态为「已结束」
2. 点进去，报告会展示结构化需求文档
3. 页面上有「导出」按钮，格式可选 **Markdown / HTML / Word** 之一

---

## 7. 管理用户

「系统配置」旁边是 **「用户管理」** 菜单（仅管理员可见）。

可以做两件事：

- 看当前系统里所有账号
- **重置某个用户的登录密码**（找不到原密码、又不想删账号时用）

> 「用户管理」菜单只在系统配置里，设置了允许普通用户注册时出现。默认是关闭隐藏的。

## 8. 常见问题

1、**看不到「去注册」链接？**
> 系统已经有用户、且注册已关闭。请联系管理员开账号。

2、**自检 AI 大模型失败？**
> 先看密钥是否对，再看 `base_url` 是否正确（很多厂商控制台上的「对话」地址 ≠ API 地址）。详见 [AI 大模型配置](llm-config.md)。

3、**自检语音识别失败？**
> 确认 FunASR Docker 容器在跑：`docker compose ps` 或者地址写错了。详见 [语音识别配置](asr-config.md)。

4、**访谈跑到一半想暂停又不想结束？**
> 点「暂停访谈」即可，不要直接关浏览器。直接关浏览器且不在存活窗口（默认 60 秒）内回来，连接会被服务端收尾。

5、**暂停后想「彻底结束」这段访谈？**
> 进访谈页点「结束访谈」就行。

6、**密码忘了？**
> 让管理员在「用户管理」里点「重置密码」。

7、**前端默认走 HTTPS，但浏览器会弹「不安全」？**
> 仓库自带的是一份演示用的自签证书，仅够让 Vite 启 HTTPS；浏览器不认识这张证书的签发者，所以会提示「不安全」，要点「高级 → 继续前往 localhost」才放行。**这只是浏览器对自签证书的固定提示，不代表连接真的有问题**。

> 如果想消除这个提示，让浏览器信任本地 HTTPS，有两种方法：
> 1、用 [mkcert](https://github.com/FiloSottile/mkcert) 把本地 CA 装进系统信任链最省事。
> 2、部署到服务器时，需要用正式的证书。
