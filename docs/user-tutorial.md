# 小智方糖 使用教程

本教程只面向**管理员**视角：从注册账号开始，到完成一次访谈、导出报告。如果你只是想试用，按顺序读完第 1～6 节即可上手。

部署 / 启动后端与 ASR 服务请看根目录 `README.md`「快速开始」一节，本文不再重复。

---

## 1. 注册首位管理员

打开浏览器，访问 `http://localhost:8848`。

如果系统里还没有任何账号，登录框会出现 **「去注册」** 链接；点它。

填三样东西：

- **用户名**：4 到 32 位的字母、数字、下划线、连字符，不能和别人重名
- **密码**：长度与字符种类有最低要求（系统拒绝太短、太简单的密码，按提示来即可）
- **确认密码**：再输一次

点「注册」。

**系统里第一个注册成功的账号会自动成为超级管理员**，后续注册的普通账号只有普通权限。

注册成功后页面会让你登录；输入刚才的用户名密码登录。

> 如果你看不到「去注册」链接，说明系统里已经有用户了，并且管理员把注册关掉了。请联系当前管理员给你开账号。

---

## 2. 进入系统配置

登录后默认进「访谈主页」（左侧菜单第一个）。普通用户这一步什么都不用做，直接跳到第 5 节。

**超级管理员** 还要先做一些配置：

点左侧菜单里的 **「系统配置」**。

---

## 3. 填 LLM 密钥

点 **LLM** 分组，至少填这四项：

- `type`：保留默认值 `openai`
- `base_url`：API 接入地址
- `api_key`：大模型厂商给你的密钥
- `model`：模型名

填完点页面上的保存。

> 这一步不填的话，等下创建访谈会被 LLM 拒绝，转写出来的内容也走不了辅导。

### 3.1 推荐：阿里云百炼

国内最省事的方案，注册就送免费额度。

注册 / 开通：

1. 浏览器打开阿里云百炼控制台：https://bailian.console.aliyun.com/
2. 用阿里云账号登录；首次进入会引导你完成实名认证
3. **关键的两步开通**——百炼要先开平台、再开服务：
   - **第一步：开通百炼平台**——控制台首页会弹窗「开通百炼大模型服务」，按提示走完即可
   - **第二步：开通具体模型**——左侧菜单「模型服务」，挑你打算用的模型（如 `qwen-plus`）点「开通」，新用户通常有免费 token 额度
4. 进入「API-Key」页面（左侧菜单 → 「API-Key 管理」），点「创建 API-Key」
5. 复制生成的密钥字符串——这就是你要填的 `api_key`，**只显示一次，关掉页面就再也看不到**

填到本项目：

| 字段 | 填什么 | 默认值（保留即可） |
| --- | --- | --- |
| `type` | `openai` | ✅ |
| `base_url` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | ✅ |
| `api_key` | 你刚才复制的 API-Key | （空，要填）|
| `model` | `qwen-plus` | ✅ |

> `qwen-plus` 性价比最高。要更强一点就改成 `qwen3-max`、`qwen-long`；要更便宜就 `qwen-turbo`、`qwen-flash`。模型名以百炼控制台实时显示为准。

### 3.3 填 ASR

点 **ASR** 分组。第一项 `ASR`类型再决定后续字段。

#### 3.3.1 推荐：本地 FunASR（**免费**，音频不出内网）

适合：内网部署、对语音数据保密有要求、想零成本接入。

部署：照 `README.md`「1.1. 启动 ASR 服务」跑 `docker compose up -d funasr`（第一次会下载约几 GB 的模型，需要耐心等）。容器起来后默认监听宿主机 `10096` 端口。

填字段：

| 字段 | 填什么 |
| --- | --- |
| `type` | `funasr_server` |
| `language` | `zh`（普通话）/ `yue`（粤语）/ `en`（英语）|
| `sample_rate` | `16000` |
| `ws_url` | `wss://localhost:10096`（Docker 启动后默认就是这个）|
| `ws_verify_ssl` | `false`（本地自签证书）|

> 容器跑没跑通：`docker compose ps` 应能看到 `funasr` 在运行；自检页面选「ASR」可以测一下。

#### 3.3.2 备选：火山引擎豆包流式 ASR（按量付费）

适合：不想自己跑 Docker、要商用稳定性。

注册 / 开通：

1. 打开火山引擎控制台：https://console.volcengine.com/
2. 用手机号或抖音账号登录，完成实名认证
3. 在「语音技术」开通「流式语音识别」服务（新用户通常有免费时长）
4. 进入「语音技术 → 应用管理」点「创建应用」，勾选「流式语音识别」能力
5. 应用创建成功后，进入 https://console.volcengine.com/speech/service/10011 页面，开通小时版的服务，然后复制`服务接口认证信息`面板的`APP ID`和`Access Token`，
6. 「流式语音识别」的服务 ID（`resource_id`）：项目里默认填的就是 `volc.bigasr.sauc.duration`，通常不用改

填到本项目：

| 字段 | 填什么 |
| --- | --- |
| `type` | `doubao_stream` |
| `language` | `zh-CN`（按语种选，其它常见：`en-US` / `ja-JP` / `vi-VN`）|
| `sample_rate` | `16000` |
| `appid` | 创建应用时系统分配的 AppID |
| `access_token` | 创建应用时和 AppID 在同一页面给出的 Access Token |
| `resource_id` | 默认 `volc.bigasr.sauc.duration` 即可 |
| `enable_multilingual` | `false`（除非你确认要开多语种识别）|

### 3.4 填 OCR（可选）

> OCR 在本项目里用于「从图片里抽取文字」相关的扩展能力（如访谈中需要识别截图、合同照片等）。如果你只用纯语音访谈，可以**完全跳过**这一节，相关功能不会受到影响。

点 **OCR** 分组。第一项 `type` 决定字段。

#### 3.4.1 推荐：百度智能云 OCR（按次计费，每月都有免费额度）

注册 / 开通：

1. 打开百度智能云控制台：https://console.bce.baidu.com/
2. 用百度账号登录，完成实名认证（个人身份证或企业营业执照）
4. 进入「公有云服务 → 应用管理」（链接：https://console.bce.baidu.com/ai-engine/ocr/app/list），点「创建应用」
5. 选「通用」下面的能力即可，提交后系统分配一个 **AK（API Key）** 和 **SK（Secret Key）**——**只在创建时显示一次**，务必复制保存

填到本项目：

| 字段 | 填什么 |
| --- | --- |
| `type` | `baidu` |
| `base_url` | `https://aip.baidubce.com` |
| `api_key` | 上面拿到的 **AK**（API Key）|
| `secret_key` | 上面拿到的 **SK**（Secret Key）|
| `model` | `general_basic`（通用文字识别；其它可选：`accurate_basic`（高精度）、`handwriting`（手写体））|

## 4. 运行自检

LLM / ASR / OCR 三家都填好后，回到配置页右上角，点 **「运行自检」** 按钮。

弹窗里会列出三类检查：

- **全部**：一次跑 ASR、LLM、OCR 三个组件
- **ASR**：单跑语音识别
- **LLM**：单跑大模型
- **OCR**：单跑图片识别

第一次点选 **「全部」**。每张卡片都会显示 `ok` 或具体失败原因。

常见失败原因：

- LLM 红字 → 多半是密钥错、或 `base_url` 填成「聊天界面」而不是 API 地址
- ASR 红字 → 看一下 FunASR Docker 容器是不是没起来：`docker compose ps` 应能看到 `funasr` 在运行；或豆包的 `appid` / `access_token` 填错
- OCR 红字 → AK / SK 漏填、或者百度账号还没开通文字识别服务。如果你不做图片提取，可以跳过 OCR 自检

全部绿灯后关掉弹窗，进入下一步。

基础能力保证：ASR和LLM正常就行了

---

## 5. 创建访谈

回到 **「访谈主页」**，点页面上的 **「新建访谈」**。

弹窗里会让你选模板、填访谈对象、背景与目标：

- 被访谈的人大概是什么角色
- 他所在的公司 / 行业 / 现状
- 你这次最想搞清的问题是啥，比如你想了解他对某个系统的建设需求，简单写写，对智能辅助很有必要

填完点「创建访谈」，会自动跳进访谈页。

---

## 6. 跑访谈

访谈页里从上到下分三块：

- **左侧**：辅导清单（系统根据对话给你「下一个该问什么」「哪些关键点还没问到」的提示）
- **右方**：实时的转写文本（你说的话 / 对方的话会一边识别一边上屏）
- **右上方**：控制按钮

### 开始 → 暂停 → 继续 → 结束

- 点 **「开始访谈」**，浏览器会请求麦克风权限，授权后转写开始
- 中途需要去接电话、回消息 → 点 **「暂停访谈」**：状态变成「已暂停」，列表里的卡片立即变灰，可以随时回来点「继续」
- 这场访谈聊完了 → 点 **「结束访谈」**：状态变成「已结束」，不能再继续

### 辅导清单的操作

左侧每条提示有两种动作：

- **忽略**：本次访谈不聊这个，就不出现在待问清单里了

边聊的过程中，AI会自动把已经澄清的内容标注好。用户只要在访谈过程中瞄一眼待问清单。

---

## 7. 查看并导出报告

访谈「已结束」后：

1. 回到访谈主页，状态为「已结束」
2. 点进去，报告会展示结构化需求文档
3. 页面上有「导出」按钮，格式可选 **Markdown / HTML / Word** 之一

---

## 8. 管理用户

「系统配置」旁边是 **「用户管理」** 菜单（仅管理员可见）。

可以做两件事：

- 看当前系统里所有账号
- **重置某个用户的登录密码**（找不到原密码、又不想删账号时用）

> 「用户管理」菜单只在系统配置里，设置了允许普通用户注册时出现。默认是关闭隐藏的。

## 9. 常见问题

1、**看不到「去注册」链接？**
> 系统已经有用户、且注册已关闭。请联系管理员开账号。

2、**自检 LLM 失败？**
> 先看密钥是否对，再看 `base_url` 是否正确（很多厂商控制台上的「对话」地址 ≠ API 地址）。

3、**自检 ASR 失败？**
> 确认 FunASR Docker 容器在跑：`docker compose ps`或者地址写错了。

4、**访谈跑到一半想暂停又不想结束？**
> 点「暂停访谈」即可，不要直接关浏览器。直接关浏览器且不在存活窗口（默认 60 秒）内回来，连接会被服务端收尾。

5、**暂停后想「彻底结束」这段访谈？**
> 进访谈页点「结束访谈」就行。

6、**密码忘了？**
> 让管理员在「用户管理」里点「重置密码」。

7、**前端默认走 HTTPS，但浏览器会弹「不安全」？**
> 仓库自带的是一份演示用的自签证书，仅够让 Vite 启 HTTPS；浏览器不认识这张证书的签发者，所以会提示「不安全」，要点「高级 → 继续前往 localhost」才放行。**这只是浏览器对自签证书的固定提示，不代表连接真的有问题**。

> 如果想消除这个提示，让浏览器信任本地 HTTPS，有两种方法：
> 1、用 [mkcert](https://github.com/FiloSottile/mkcert) 把本地 CA 装进系统信任链最省事。
> 2、部署到服务器时，需要用正式的证书。
